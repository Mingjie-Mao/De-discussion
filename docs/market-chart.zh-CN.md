# 市场图表（2026-10-08）

## 原因

接入真实 API 时，周期按钮被缩为一个，五分钟观测与原始演示数据混在一起。
分时又使用平坦蜡烛，时间跨日只显示时分，结果看起来像零散短线。
旧演示的分时、周、月走势使用随机生成器，不是数据库中的长期历史。

## 当前显示

| 入口 | 数据和坐标 |
| --- | --- |
| 原始历史（默认） | 数据库 `IMPORTED_DEMO` OHLC，四校各 6 根，共 24 根。单独显示，不追加实时价格。 |
| 分时 | `LIVE` 五分钟观测的收盘值折线；悉尼当天 00:00 至当天结束，按实际时间定位，未来时段留空。 |
| 日 K | 悉尼自然日汇总开、高、低、收。 |
| 周 K | 悉尼周一开始的自然周汇总。 |
| 月 K | 悉尼自然月汇总。 |

日历时区统一为 `Australia/Sydney`，支持夏令时 23/25 小时日。
每桶使用首次开盘、最高、最低和末次收盘，按时间排序；日/周/月最多显示最近 40 桶。
分时保留当天实际观测，不限制为 40 个点。没有记录的时段不生成数据。
蜡烛上下留白、显示价格轴，平盘显示十字线而非小圆点。
按钮支持横向滚动，不因窄屏挤掉周/月入口；页面旋转保留已选择周期。

顶部价格、买卖、持仓和余额仍以服务器为准。涨跌显示“24 小时”，
因为价格由滚动 24 小时论坛活动计算；旧活动退出窗口可导致大幅下降。
未加载时显示等待状态及“—”，而非把缺失行情当作真实零值。

## 数据限制

新市场只有几天真实历史，因此周/月只有少量、甚至一根蜡烛属正常。
原始六根历史保持原样；不把随机走势、样例交易和真实行情混在一起。

当前接口每校最多返回最近 288 根原始记录，所以周期图仅汇总该返回范围，
并非完整长期行情。将来导入记录被截掉时，需要服务端独立历史接口。
实时观测在访问时生成，不代表无人值守每五分钟自动采集。

本次只改客户端，复用已有 `source` 和 `at`，无需数据库迁移或后端部署。
